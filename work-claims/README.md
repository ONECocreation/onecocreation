# work-claims — one file per lane

A lane's first commit adds `work-claims/task-NNN.md` (task, house, branch, base, OWNS, stamp).
The shared `WORK-CLAIM.md` at the repo root is history only — nothing writes it any more
(it was a guaranteed merge conflict on every parallel wave; kimi's WORKFLOW-REVIEW-2, 0018.06.17 a₿).
Claim files are never deleted by the lane; the orchestrator prunes them when a task archives.
